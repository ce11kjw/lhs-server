LHS 统一管理中心

已把原 `admin-users.html` 迁移到 `LHS-admin`，并在同一管理入口中接入游戏后台、代理操作后台和分销系统后台。目录代理会把不同前缀转发到不同端口。

/game -> 8080 游戏用户管理 玩家查询、编辑、任务、批量发放、手动充值、操作日志、大区管理等原 `admin-users` 能力。 独立模块 游戏后台模块中心 把用户数据、代理商、充值配置、操作日志和大区数据拆成可单独打开的后台模块入口。 /dist -> 3001 分销管理 分销代理、佣金流水、提现审批、全局统计和后台鉴权，直接通过目录代理进入分销系统。 代理登录 分销代理端 给代理商使用的登录入口、团队数据、佣金明细和提现申请页面。
